# Workoholic

Arbeitsseite für Anfragen von Kollegen, eigene Todos und Aufgaben, mit Stempeluhr zum **Eindongeln / Ausdongeln**, Terminen, Routinen, Team, Ablage, WaffG-Prüfstand – und dem Bereich **Schreiben** zum Aufnehmen von Vorgängen per Antippen (derzeit: Verkehrsunfallflucht ohne Personenschaden, Vermisste Person, Häusliche Gewalt, Allgemeines/Einsatzanlass für Strafanzeigen, Eintreffsituation, Schilderungen, Maßnahmen nach dem PsychKG, Zusatzbausteine wie Personenbeschreibung und Maßnahmen – und der Vorgang aus Abschnitten, der mehrere davon zu einem Sachverhalt kombiniert).
Alle Daten sind **Ende-zu-Ende verschlüsselt**. Synchronisiert wird über ein eigenes privates GitHub-Repo, das nur Chiffretext enthält.

---

## Sicherheit

### So funktioniert die Verschlüsselung

| Baustein | Umsetzung |
| --- | --- |
| Schlüssel aus dem Master-Passwort | **Argon2id**, 64 MiB Speicher, 3 Durchläufe, 16-Byte-Zufallssalz |
| Daten­verschlüsselung | **AES-256-GCM** mit zufälligem 256-Bit-Datenschlüssel und neuem 96-Bit-IV bei jedem Speichern |
| Schlüsselverwaltung | Der Datenschlüssel ist zweifach verpackt: mit dem Master-Passwort und mit einem **Wiederherstellungsschlüssel** (160 Bit). |
| Manipulationsschutz | Parameter und Schlüsselblock sind kryptografisch an die Daten gebunden. Einen Passwortwechsel übernehmen Geräte nur, wenn er von einem deiner entsperrten Geräte signiert wurde. |
| Metadaten | Klartext wird vor der Verschlüsselung auf 4-KB-Blöcke aufgefüllt, damit die Dateigröße kaum etwas über den Inhalt verrät. |

**Klartext verlässt nie dein Gerät.** Weder im Browser-Speicher noch auf GitHub noch im Backup liegt irgendetwas unverschlüsselt.
Auch dein GitHub-Token wird verschlüsselt abgelegt.

### Was andere sehen können

- **GitHub** sieht eine Datei mit zufälligen Bytes, ihre ungefähre Größe (in 4-KB-Stufen) und wann sie sich ändert. Der Verlauf wird täglich auf einen einzigen Commit eingedampft.
- **Fremde Server** sehen gar nichts. Schriften und die Argon2-Bibliothek liegen im Repo. Eine strenge Content-Security-Policy erlaubt Verbindungen ausschließlich zu `api.github.com`. Es gibt kein Tracking und keine Analyse, die Seite verschickt keinen Referrer und ist für Suchmaschinen gesperrt.
- **Dein Gerät:** Im Browser-Speicher liegt nur der verschlüsselte Tresor. Nach Inaktivität (einstellbar: 5–60 Min) sperrt die Seite automatisch. Beim Sperren wird sie neu geladen, damit Klartext und Schlüssel komplett aus dem Arbeitsspeicher verschwinden.

### Ehrliche Grenzen

Keine Software schützt gegen alles. Diese Punkte liegen bei dir:

1. **Master-Passwort:** Nimm ein langes, das du nirgends sonst verwendest, am besten einen Satz aus mehreren Wörtern. Die App lässt nichts unter 12 Zeichen und keine schwachen Muster zu.
2. **GitHub-Account mit Zwei-Faktor-Anmeldung (Passkey oder Authenticator) absichern – Pflicht!** Wer deinen GitHub-Account übernimmt, könnte den App-Code verändern und dein Passwort beim nächsten Entsperren abgreifen.
3. **Gerät:** Gegen Schadsoftware, Keylogger oder jemanden, der an deinem *entsperrten* Gerät sitzt, hilft keine Verschlüsselung. Halte Betriebssystem und Browser aktuell.
4. **CSV-Export** der Arbeitszeiten, **Kalender-Export** und **Textexport** eines Vorgangs sind absichtlich Klartext. Die App warnt vorher.
5. **Passwort und Wiederherstellungsschlüssel verloren = Daten verloren.** Das ist der Preis echter Ende-zu-Ende-Verschlüsselung: Niemand hat einen Generalschlüssel.

## Einrichtung (einmalig, ca. 5 Minuten)

1. **Tresor-Repo anlegen:** GitHub → *New repository* → Name z. B. `workoholic-tresor` → **Private** → *ohne* README → *Create*.
2. **Token erstellen:** GitHub → *Settings* → *Developer settings* → *Personal access tokens* → *Fine-grained tokens* → *Generate new token*
   - *Repository access:* **Only select repositories** → nur `workoholic-tresor`
   - *Permissions → Repository permissions → Contents:* **Read and write**
   - Ablaufdatum nach Wunsch. Danach in der App einfach einen neuen Token eintragen.
3. **App öffnen**, Master-Passwort festlegen und den **Wiederherstellungsschlüssel** sicher notieren (Papier oder Passwort-Manager).
4. **⋯ → Sicherheit & Sync**: Repo (`deinname/workoholic-tresor`) und Token eintragen → *Verbinden*.
5. **Weitere Geräte:** App öffnen → *„Ich habe schon einen Tresor auf einem anderen Gerät“* → Repo, Token und Master-Passwort eingeben.

Änderungen auf mehreren Geräten gleichzeitig werden automatisch zusammengeführt: Pro Eintrag gewinnt der neueste Stand, und Löschungen kommen überall an.

## Von überall erreichbar: Hosting

Die Seite ist rein statisch (HTML/JS), ein eigener Server ist nicht nötig. Ihr Code enthält keine Geheimnisse; die Sicherheit beruht allein auf der Verschlüsselung.

- **GitHub Pages:** Im Code-Repo *Settings → Pages* → Branch wählen, Ordner `/ (root)`. Bei einem **privaten** Repo braucht das GitHub Pro. Alternativ stellst du dieses Code-Repo öffentlich; die Daten liegen ohnehin getrennt im privaten Tresor-Repo. Danach läuft die Seite unter `https://<user>.github.io/workoholic/` und lässt sich am Handy über *„Zum Home-Bildschirm“* wie eine App nutzen.
- **Lokal:** `index.html` per Doppelklick öffnen. Funktioniert inklusive Sync.

### Aktualisierung: neuer Stand kommt von selbst

Als Home-Bildschirm-App hält das iPhone Seite und Skripte im Speicher – ohne Vorkehrung bleibt nach einer Veröffentlichung die alte Fassung sichtbar. Deshalb trägt jede Veröffentlichung einen **Stand** (Stempel `JJJJMMTT-HHMM`):

- **Sichtbar:** unten auf dem Sperrbildschirm („Stand 13.11.2026, 14:24 Uhr“) und unter *Sicherheit → Version*. Dort gibt es auch „Nach neuer Version suchen“.
- **Erkennen:** `js/update.js` fragt beim Start und bei jeder Rückkehr in die App (höchstens alle 5 Minuten) `js/version.js` am Zwischenspeicher vorbei ab und vergleicht mit dem geladenen Stand.
- **Holen:** Ist der Tresor gesperrt und noch nichts getippt, lädt die App den neuen Stand sofort. Ist er entsperrt, erscheint „Neue Version verfügbar – Aktualisieren“; spätestens beim nächsten Sperren wird der neue Stand geladen. Die Daten bleiben unberührt, es ist nur das Passwort neu einzugeben.
- **Frisch:** Alle Skripte hängen am Stand (`?v=…`), die Seite selbst wird über eine eigene Adresse je Stand geholt – ein alter Zwischenspeicher kann nichts Altes mehr liefern.

**Vor jeder Veröffentlichung:** `tools/stand.sh` ausführen (setzt den Stempel in `index.html` und `js/version.js`), `tools/stand.sh pruefen` kontrolliert, dass alles übereinstimmt. Ohne neuen Stempel bemerkt die App die Veröffentlichung nicht.

## Funktionen

**Erfassen**
- **Anfrage** (von wem?), **Todo**, **Aufgabe** oder **Stundenbuchung** (siehe unten).
- Dringlichkeit:
  - *Einmalig*
  - *Ultimatum* (Frist mit Countdown)
  - *Dauer* (Aufwand plus ▶-Timer)
  - *Schnellstmöglich*
  - *Wiederkehrend* (täglich, werktags, wöchentlich, monatlich)
- Status: offen, in Arbeit, wartet auf Rückmeldung.
- **Wichtig:** Haken im Eintrag oder `*` in der Schnellerfassung. Wichtige Einträge stehen im Planner ganz oben (Gruppe „Wichtig“, älteste zuerst) und tragen einen ★.
- Schnellerfassung: `@Sabine Zahlen schicken !` legt eine dringende Anfrage von Sabine an. `#aufgabe` / `#todo` / `#buchung` wählt die Art, `*` markiert als wichtig, `⇧ Enter` öffnet die Details.

**Überblick**
- Planner nach Dringlichkeit gruppiert.
- Fokus-Karte mit Live-Countdown.
- Filter, Suche, Kollegen-Avatare und Kalender mit Fristen.

**Dienste & Überstunden**
- **Eindongeln** (Tippen, Ziehen oder Taste `D`) öffnet *Dienst beginnen* mit den Abschnitten Schicht, Besatzung und Einsatzmittel: Schicht aus dem Katalog wählen (ein vorab eingetragener Dienst ist schon vorgewählt), dazu, **mit wem** du unterwegs bist – Kolleginnen und Kollegen aus dem Team antippen oder neu eintragen (landen automatisch im Team), „Wie zuletzt“ übernimmt die letzte Besatzung – und optional das **Einsatzmittel** (Funkrufname). Die Vorschau zeigt die Routinen dieser Schicht und die Zahl offener To-dos. Beginn ist jetzt, das geplante Ende kommt aus der Vorlage; *Andere Zeiten …* erlaubt freie Zeiten und behält die Besatzung.
- **Schichtbriefing:** Nach dem Bestätigen fliegen alle offenen To-dos ein – wichtige ganz oben, dann die ältesten zuerst –, dazu die Termine in der Schichtzeit, Einsätze früherer Schichten ohne Abschluss und die Routinen der Schicht. Antippen öffnet den Eintrag.
- Beginn und geplantes Ende lassen sich jederzeit über den Stift ändern, auch während des Dienstes.
- **Länger gemacht:** zwischendurch oder danach per `+15 Min` / `−15` eintragen. Wer nach dem geplanten Ende **ausdongelt**, wird gefragt, ob die Mehrzeit als Überstunden zählt (auf 15 Minuten gerundet).
- Ausdongeln vergessen? Die App fragt, ob das geplante Ende oder „jetzt“ gilt.
- Beim Ausdongeln nennt die App, was in der Schicht noch offen ist: laufende Einsätze (werden mit dem Dienstende beendet), Einsätze ohne Abschluss und nicht abgeschlossene Routinen.
- **Überstunden-Konto:** Woche, Monat, Jahr und Gesamt, dazu die letzten Dienste mit Überstunden.
- **Dienste eintragen** für jeden Tag, auch im Voraus (Nachtdienste enden automatisch am Folgetag). Überschneidungen werden abgefangen; Pausen werden nach Arbeitszeitgesetz geprüft.
- **Dienste-Katalog:** Schichtbezeichnung, Beginn, Ende, Pause und Farbe frei änderbar. Vorlagen lassen sich anlegen und löschen, und der Katalog wird zwischen deinen Geräten synchronisiert.
- Wochenchart mit Diensten, Überstunden (gestapelt) und geplanten Diensten; im Kalender sind geplante Dienste markiert.
- CSV-Export aller Dienste mit Pause, Arbeitszeit und Überstunden.

**Schicht & Einsätze (Bereich *Heute*)**
- Die **Schichtkarte** oben zeigt die laufende Schicht mit Besatzung und Einsatzmittel, ihre Einsätze und Routinen. Ein Tag in der Woche antippen zeigt die Schicht dieses Tages.
- **+ Einsatz** (oder Taste `E`) legt den nächsten Einsatz an (E1, E2 …, Beginn jetzt). Das Blatt hat drei nummerierte Abschnitte, deren Nummer gelb wird, sobald sie erledigt sind: **1 Lage** (Stichwort, Ort), **2 Verlauf** (Beginn/Ende, auch über Mitternacht, Notizen), **3 Abschluss**.
- **Vorschläge** erscheinen nur, solange das Stichwort leer ist: die sechs meistgenutzten, der Rest hinter *Mehr*; beim Tippen werden sie gefiltert. Bei Maßnahmen stehen vier Vorschläge da, bereits angelegte verschwinden.
- **Abschluss:** erst das Ergebnis als Freitext („Lage beruhigt, Platzverweis“), dann die Folgearbeiten: *Keine Maßnahmen* (und keine schriftlichen Arbeiten) oder *Maßnahmen*. Nur bei *Maßnahmen* erscheinen **To-dos** – sie hängen am Einsatz, erscheinen gleichzeitig im Planner (mit Einsatz-Pille) und lassen sich als wichtig markieren. Erledigt man sie im Planner, gilt der Einsatz als abgeschlossen.
- **Schriftliche Arbeit** direkt aus dem Einsatz starten (Vorgang aus Abschnitten, Verkehrsunfallflucht, Vermisste Person, Häusliche Gewalt, Schilderungen): Datum, Uhrzeit, Rufname und Besatzung sind vorbelegt; ein verknüpftes To-do erledigt sich, sobald der Vorgang als fertig markiert ist.
- **Routinen je Schicht:** Im Routinen-Editor an Schicht-Vorlagen und/oder Einsatzmittel binden („Fahrzeugcheck“ nur für `Stf 21/03`, „Schichtübergabe“ nur für Früh- und Spätdienst). Gebundene Routinen erscheinen in Vorschau, Briefing und Schichtkarte mit Fortschritt je Schicht.

**Stunden für Kollegen buchen**
- Eintragsart *Stunden buchen*: Kollegin/Kollege, Datum des Dienstes, Dienst (aus dem Katalog) und Stunden in 15-Minuten-Schritten.
- Landet als Todo im Planner (Filter „Buchungen“) und wird abgehakt, sobald du die Stunden im System eingetragen hast.
- Schnellzugriff: Knopf *Stunden für Kollegen merken* im Überstunden-Konto.

**Termine (Bereich *Heute*, Kalender)**
- Tag im Kalender antippen → *+ Termin*: Titel, Datum, ganztägig oder mit Uhrzeit, Ort, Erinnerung, Notizen.
- **In meinen Kalender:**
  - *Apple / Outlook (.ics)* erzeugt eine Standard-Kalenderdatei (RFC 5545) inklusive Erinnerung. Öffnen genügt, dein Kalender übernimmt den Termin.
  - *Google* und *Outlook.com* öffnen den Termin direkt beim jeweiligen Anbieter. Erst dabei verlässt der Termin dein Gerät.
- *.ics*-Knopf im Kalender: alle Termine (wahlweise plus geplante Dienste) in einer Datei exportieren.

**Routinen (Schablonen)**
- Eigene Abläufe mit Schritten (eine Zeile pro Schritt), Farbe und Rhythmus: bei Bedarf, täglich, werktags, wöchentlich oder monatlich.
- *Starten* öffnet einen Durchlauf zum Abhaken (mit Uhrzeit pro Schritt). Er lässt sich unterbrechen und später fortsetzen; *Abschließen* speichert ihn im Verlauf.
- Fällige Routinen werden markiert und in der Navigation gezählt.

**Team**
- Personenbaum: Wer berichtet an wen, **Amtsbezeichnung** (Auswahlliste, z. B. POK, PKin – erscheint in Besatzungen und Berichten als „Amtsbezeichnung Nachname“; aus älteren Rollen wie „Pkin“ oder „Polizeioberkommissarin“ wird sie erkannt), beliebig viele Rollen pro Person, optional Kontakt.
- Notizen je Person mit automatischem Zeitstempel, chronologisch nach Tagen gruppiert (neueste oben). Nachträgliche Änderungen werden als „bearbeitet“ markiert.
- Offene Anfragen und Stundenbuchungen der Person aus dem Planner erscheinen direkt in ihrem Bereich.

**Ablage (Dateien & Dokumente)**
- Dateien bis 20 MB werden **auf dem Gerät verschlüsselt** (AES-256-GCM, an die Datei gebunden, auf 16-KB-Blöcke aufgefüllt) und im Browser-Speicher (IndexedDB) abgelegt.
- Mit Sync landen sie verschlüsselt als `files/<zufällige-ID>` im Tresor-Repo; Dateinamen stehen nur im verschlüsselten Tresor. Andere Geräte laden sie erst beim Öffnen.
- Vorschau für Bilder, Texte, Audio/Video, dazu Herunterladen, Teilen, Ordner, Notizen und „Nur in der Cloud behalten“ (lokale Kopie löschen).

**WaffG-Prüfstand**
- Geprüft wird nach dem amtlichen Wortlaut: WaffG zuletzt geändert durch Art. 12 Abs. 20 G v. 22.10.2026 (BGBl. I Nr. 318), dazu § 22a KrWaffKontrG sowie StGB/OWiG für Vorsatz, Irrtum, Versuch und Konkurrenzen. Die Texte stammen aus dem täglichen Archiv von gesetze-im-internet.de und sind in der App enthalten – es wird nichts nachgeladen.
- **Gegenstände:** Messer (Einhand, feststehend mit Klingenlänge, Spring- mit Ausnahme nach Nr. 1.4.1 Satz 2, Fall-, Faust-, Butterfly-, getarnte Messer), scharfe Schusswaffen (Pistole, Revolver, Langwaffe, Vollautomat, Pumpgun, getarnte, wesentliche Teile), SRS-Waffen, Druckluft/Softair, Antik-, Deko- und Salutwaffen, Munition, Hieb-, Stoß- und Schlagwaffen, Reizstoff- und Elektroimpulsgeräte, Armbrust, Präzisionsschleuder, Brand-/Sprengvorrichtungen, Anscheinswaffen, Kriegswaffen.
- **Umgangsarten (§ 1 Abs. 3):** Besitz, Erwerb, Führen, Überlassen, Schießen, Verbringen/Mitnehmen, Herstellen/Bearbeiten, Handel – dazu die Aufbewahrung (§ 36, § 52 Abs. 3 Nr. 7a).
- **Umstände:** Ort (öffentlich, Veranstaltung § 42, Personenfernverkehr § 42b, Verbotszone § 42 Abs. 5, fremder oder eigener Hausrechtsbereich), Zugriff (zugriffsbereit, mehr als drei Handgriffe, verschlossenes Behältnis), geladen, Zweck (Beruf, Sport, anerkannter Zweck, Gastronomie, Film …), Erlaubnisse (WBK, Waffenschein, kleiner Waffenschein, Jagdschein, Schießerlaubnis, behördliche Ausnahmen), Fund/Erbe, Waffenverbot nach § 41, Alter, Vorsatz oder Fahrlässigkeit.
- **Ergebnis:** alle einschlägigen Prüfpunkte mit Norm und Strafrahmen (z. B. § 51, § 52 Abs. 1 Nr. 2 Buchst. b, § 52 Abs. 3 Nr. 9, § 53 Abs. 1 Nr. 21a bis 21c), Fahrlässigkeit, Versuch, minder und besonders schwere Fälle, Einziehung, Konkurrenzen (§ 52 StGB, §§ 19, 21 OWiG).
- **Subsumtion:** Jede Prüfung ist im Gutachtenstil aufgebaut (Obersatz, objektiver Tatbestand Merkmal für Merkmal mit +/−/?, subjektiver Tatbestand, Rechtswidrigkeit und Schuld, Ergebnis).
- **i-Knöpfe:** Hinter jeder Auswahl, jedem Abschnitt und jeder Fundstelle stehen Wortlaut, Tatbestandsmerkmale, Prüfhinweise und Abgrenzungen sowie geprüfte Rechtsprechung (BGH 3 StR 81/22, 4 StR 431/06).
- Text für Anzeige oder Vermerk mit Tatbestand je Prüfpunkt: frei bearbeitbar, kopierbar, als Aufgabe in den Planner. „Speichern“ legt die Prüfung verschlüsselt mit Zeitstempel ab; ältere Prüfungen werden übernommen.
- **Keine Rechtsberatung.** Nicht abgebildet sind u. a. Altbesitz (§ 58), Melde- und Anzeigepflichten im Detail, Sportschützen- und Sammlerregeln sowie der Inhalt einzelner Landesverordnungen und Allgemeinverfügungen.

**FE-Prüfung (Freiheitsentziehung, NRW) – Entscheidungsbaum**
- **Eine Frage pro Blatt:** Zuerst die Ausgangslage (Straftat, Ordnungswidrigkeit, drohende Tat, hilflose Person, psychische Krise, missachtete Anordnung, unklare Identität, Kind/Jugendliche, Fahndungstreffer/Befehl, weitere Fälle). Jedes weitere Blatt zeigt nur die Wege, in die sich die Freiheitsentziehung dann noch auffächert – z. B. Straftat → Täter sichern → frische Tat, Haftgründe, schwere Straftat (§ 112 Abs. 3), beschleunigtes Verfahren.
- **An jeder Abzweigung**, was dafür vorliegen muss („Dafür muss vorliegen“), plus i-Knopf mit Voraussetzungen, Wortlaut, Prüfhinweisen und Rechtsprechung.
- **Lexikon:** eigener Reiter mit allen Begriffen der Freiheitsentziehung von A bis Z, Suche (bester Treffer zuerst) und Themenfilter (Festnahme, Haftgründe, Identität & OWi, Gefahrenabwehr, Sonderrecht, Verfahren). Fachwörter in Fragen, „Dafür muss vorliegen“, Ergebnissen und Erläuterungen sind gepunktet unterstrichen – antippen öffnet den Eintrag. Jeder Eintrag: „Kurz gesagt“, „Liegt vor / liegt nicht vor“ nebeneinander, Argumente dafür und dagegen, 126 per Recherche belegte Urteile (BVerfG, BGH, EGMR, OLG, VG/OVG) als Einzeiler – spricht dafür / dagegen, antippen für Aktenzeichen und Link zur Fundstelle, „Im Einsatz“; Definition, Meinungsstreit, Kommentar und Wortlaut aufklappbar; verwandte Begriffe und Zurück-Schritt.
- **Ergebnis:** „Freiheitsentziehung rechtmäßig“ mit Rechtsgrundlage, erfüllten Voraussetzungen des gegangenen Weges, Rechtsfolge und Formvorschriften (Belehrung, Benachrichtigung, Richter, Fristen) – oder „nicht rechtmäßig“ mit Grund, Abbruchstelle und Alternativen – oder ein anderer Weg ohne Freiheitsentziehung (z. B. Sicherheitsleistung § 127a, Haftbefehl beantragen, Platzverweis). „Zusätzlich prüfen“ / „Stattdessen prüfen“ zweigen direkt weiter ab; **Vermerk kopieren** übernimmt Weg und Ergebnis.
- 67 Fragen, 72 Ergebnisse, 35 Rechtsgrundlagen (StPO, OWiG, PolG NRW, PsychKG NRW, BGB, JuSchG, SGB VIII, AufenthG, IfSG); bis zu 11 Fragen bis zum Ergebnis. Polizei oder Privatperson umschaltbar (Privatpersonen nur § 127 Abs. 1 StPO).
- **Dein Weg:** Am Desktop Seitenleiste mit allen Schritten und erfüllten Voraussetzungen, am Handy einzeilige Wegleiste – jeder Schritt antippbar zum Neu-Abzweigen.
- **Alle Wege:** Übersicht, aus demselben Baum erzeugt, nach Ausgangslage aufgeklappt; jede Frage und jedes Ergebnis springt mit vollständigem Weg in die Entscheidung.
- **Diesen Weg wählen → Bericht:** Beim Ergebnis „rechtmäßig“ zeigt ein Knopf den ganzen Weg noch einmal chronologisch (Frage → Antwort → erfüllte Voraussetzung) zum Bestätigen. Danach entsteht unter „Schreiben“ ein **FE-Bericht**, vorausgefüllt mit Rechtsgrundlage und Prüfweg: männlich oder weiblich (steuert die Satzführung), Lage, **Begründung je Voraussetzung** (fester Satzanfang, grau die Fortsetzung), **Formvorschriften-Check** passend zur Rechtsgrundlage (StPO, Jedermann, Identität, § 164, Blutprobe, PolG NRW, Jugendschutz, Sonderrecht, Vollzug/Vollstreckung) – je Punkt erledigt, nicht erfolgt (mit Grund) oder entfällt, mit Uhrzeit. Ergebnis: Vermerk, Kurzsachverhalt, **offene Punkte mit Angriffspunkten** (z. B. fehlende Belehrungsinhalte nach § 114b, keine Benachrichtigung, Fixierung ohne Richter) und Personalien.
- Bundesrecht im amtlichen Wortlaut (Stand 07.11.2026); **PolG NRW, PsychKG NRW und Art. 5 EMRK sinngemäß** – Nummerierung und Höchstdauern vor Verwendung am aktuellen Wortlaut prüfen. Keine Rechtsberatung.

**Schreiben (Schriftliche Arbeiten)**
- **Eingabe in Folien** – in allen schriftlichen Arbeiten gleich:
  - **Oben steht, wo du bist:** ein beschrifteter Knopf für den Rückweg („Vorgang“, „Personen“, „Alle Vorgänge“), der Abschnitt mit seiner Stelle im Vorgang („Eintreffsituation · Abschnitt 2 von 3“), darunter „Folie 2 von 3“ und rechts „Gespeichert“ – jede Eingabe ist sofort verschlüsselt gesichert, Zurückgehen nimmt nichts weg.
  - **Unten ist immer dieselbe Leiste:** links „Zurück“ (die Folie davor), rechts der eine nächste Schritt („Weiter“, auf der letzten Folie „Fertig“).
  - **Die Seite wechselt nur über diese Knöpfe.** Beim Antippen und Tippen bleibt sie stehen: keine automatischen Sprünge zur nächsten Frage, die angetippte Frage bleibt an ihrer Stelle, auch wenn darüber oder darunter etwas dazukommt. „Heute“ und „Jetzt“ setzen nur – ein zweiter Tipp löscht nichts. Einzige Ausnahme, und nur auf Wunsch: Im Vor-Ort-Modus der Verkehrsunfallflucht lässt sich „von selbst nach der Antwort“ einschalten (siehe dort).
  - **Nach dem Entsperren** geht ein offener Vorgang auf der Folie wieder auf, auf der man war (die App lädt beim Sperren neu).
  - **Je Folie ein Thema**, das möglichst auf einen Bildschirm passt. Am Handy gehört beim Schreiben der ganze Bildschirm der Folie (App-Kopf und Bereichsleiste sind solange ausgeblendet).
  - **Am Ende jedes Abschnitts** steht eine Abschluss-Folie: der fertige Text, groß „Text kopieren“, unten „Bearbeiten“ und der Weg weiter – im Vorgang „Weiter: nächster Abschnitt“, beim letzten „Gesamtsachverhalt“. Seltenes (Abschnitt löschen, als Datei, weitere Abschnitte anfügen) steht klein darunter.
  - Einsatzanlass (wann · wer · welcher Einsatz · wo), Eintreffsituation (worum geht es · wer war vor Ort · sonst noch; je Person: wer · wo angetroffen · verletzt), Schilderungen (je Person: Belehrung · Tatvorwurf · Alkohol und Drogen · wem gegenüber · Schilderung · Strafantrag · Kontrolle) und Häusliche Gewalt sind so in kurze Folien geteilt; die übrigen Module nutzen denselben Rahmen mit ihren bisherigen Schritten.

Danach Örtlichkeit, Fahrzeug und Schaden, Spuren, Umfeld; zum Schluss, was sich auch im Wagen nachtragen lässt (Einsatzzeit, Meldung, Unfallmitteilung, Lichtbilder, Asservate, Einsatzende, Bewertung).

Grundsatz: **Tatsachen frei, Wertungen antippen** – die Feststellungen stehen frei mit Leitfragen (Wertungswörter wie „aggressiv“ werden markiert: woran erkennbar?), die Folgerungen werden angetippt und erscheinen als fertige Sätze („Aufgrund der vorstehend beschriebenen Feststellungen …“), aber erst, wenn Feststellungen eingetragen sind. Unter jedem Schritt steht der **fertige Text dieses Abschnitts**. **Wer was wann** angeordnet, ausgesprochen oder getan hat, wird überall mit Uhrzeit erfasst: Anordnung und Ausspruch der Ingewahrsamnahme, Bekanntgabe des Grundes (§ 37), Androhung und Zwang, Fesselung (§§ 61, 62), Durchsuchung und Verwahrung (§§ 39, 43), Gewahrsamsfähigkeit (Gewahrsamsvollzugsverordnung), Benachrichtigung inkl. Sorgeberechtigte/Betreuer, **richterliche Entscheidung** (Art. 104 Abs. 2 GG → § 36 Abs. 1 PolG NRW → §§ 415 ff. FamFG): herbeigeführt, **nachts nicht erreichbar** (Versuch mit Person, Uhrzeit und Ergebnis; Nachtzeit nach § 104 Abs. 3 StPO wird aus Datum und Uhrzeit erkannt; danach mit Beginn des Bereitschaftsdienstes beantragt oder vorher entlassen; Hinweis, wenn die Ingewahrsamnahme zur Tageszeit lag, BVerfGE 105, 239) oder entbehrlich nach § 36 Abs. 1 Satz 2 mit Pflicht-Prognose. Am Ende der **fertige Text**, der sich von Hand anpassen lässt. Ergebnis-Reiter: Bericht, **Antrag AG** (§ 417 Abs. 2 FamFG), **Zeitleiste** (Uhrzeiten, Nachtzeit, Frist „Ende des Folgetages“), Kurzfassung, offene Punkte, Personalien. Im Text stehen Amtsbezeichnung und Nachname; ein Fahrzeug → Einzahl („erhielt die Streifenwagenbesatzung“).

- **Vorgang aus Abschnitten** (Kachel „VG“, ganz oben): mehrere Abschnitte zu einem Sachverhalt kombinieren. Abschnitte antippen – sie reihen sich an ihrer üblichen Stelle ein (Allgemeines → Eintreffsituation → Schilderungen → Häusliche Gewalt → Unfallörtlichkeit → Blutprobe → PsychKG → Gewahrsam), „Üblicher Anfang“ legt die ersten drei auf einmal an, ↑ ändert die Reihenfolge, ✕ entfernt einen Abschnitt (mit Rückgängig). Jeder Abschnitt öffnet seine gewohnte Maske; oben steht „Abschnitt 2 von 3“ mit Sprung zum Abschnitt davor und danach, der Zurück-Pfeil führt in den Vorgang, und am fertigen Abschnitt stehen „Zum Vorgang“ und „Weiter: …“ zum nächsten. In der Vorgangsliste steht nur der Vorgang, nicht seine Abschnitte; Löschen nimmt die Abschnitte mit. Ein einzeln angelegter Abschnitt (Allgemeines, Eintreffsituation, Schilderungen …) wird über „+ Weitere Abschnitte“ oben in seiner Maske nachträglich zum ersten Teil eines Vorgangs.
  - **Die Abschnitte bauen aufeinander auf** (Kontext-Matrix in `js/vorgang.js`): Die **Besatzungen aus „Allgemeines“** sind in allen Folgeabschnitten die Auswahl, sobald nach einer Kollegin oder einem Kollegen gefragt wird (belehrt durch, gegenüber, festgestellt durch, angeordnet durch …) – solange im Abschnitt nicht von Hand eine eigene Besatzung eingetragen wird. Die **Personen der Eintreffsituation** stehen in den Schilderungen unter „Aus Eintreffsituation übernehmen“: antippen statt neu anlegen. Name, Anrede, Rolle und die Art (Strafanzeige/Verkehr) kommen von dort und folgen späteren Änderungen; die **Verletzungen stehen nur in der Eintreffsituation**, in der Schilderung wird danach nicht noch einmal gefragt. Namenskürzel fallen in allen Abschnitten gleich aus, auch wenn eine Person nur in einem vorkommt. Jede Person trägt eine **feste Kennung**: Wird ihr Name berichtigt – auch bei jemandem, der nur in den Schilderungen steht –, kommt das in allen Abschnitten an, die sie verwenden (Maßnahmen, Blutprobe, PsychKG, Gewahrsam). Jeder Abschnitt bringt sich beim Abgleich selbst in Form, auch wenn er gerade nicht offen ist: Was in einem geändert wird, stimmt sofort in den anderen und im Gesamtsachverhalt. Unter jedem Abschnitt steht, was er übernimmt.
  - **Nummern nach Reihenfolge** (abschaltbar): Alle Überschriften des Gesamtsachverhalts werden **fortlaufend** gezählt – Allgemeines, Eintreffsituation, Schilderungen, jeder Teil der Häuslichen Gewalt, Unfallörtlichkeit, die beiden Überschriften der Blutprobe, PsychKG und Gewahrsam. Die Abschnittsnummer wird in den Abschnitten dann nicht mehr gefragt. Abgeschaltet behält jeder Abschnitt die Nummer, die du dort einträgst.
  - **Orte nur einmal eintragen:** Die Häusliche Gewalt übernimmt den Tatort – Anschrift aus der Einsatzörtlichkeit von „Allgemeines“, Gebäude, Geschoss und Seite der Wohnung aus dem Ort-Assistenten der Eintreffsituation – und zeigt ihn als Zeilen mit „Ändern“; steht die Ankunft schon in der Eintreffsituation, wird sie dort nicht noch einmal gefragt. Wo sonst nach einem Ort gefragt wird (Gewahrsam: „Wo angetroffen?“, „Aus welcher Wohnung?“; Anschrift der betroffenen Person), stehen Einsatzanschrift und Antrefforte als Vorschlag zum Antippen darunter.
  - **Folgeabschnitte fragen nicht doppelt** (Blutprobe, PsychKG, Gewahrsam, Unfallörtlichkeit): Was der Vorgang schon weiß, steht als Zeile mit „Ändern“ da, statt noch einmal abgefragt zu werden – **Kräfte** und **Datum** aus „Allgemeines“, die **betroffene Person** aus Eintreffsituation, Schilderungen oder einem anderen Folgeabschnitt. Steht im Vorgang genau eine Person (Zeugen zählen nicht), ist sie eingetragen; bei mehreren genügt ein Tipp auf den Namen. Nur das Fehlende (Geburtsdatum, Anschrift) wird gefragt und wandert von dort in die anderen Folgeabschnitte. Wird der Name in der Eintreffsituation berichtigt, stimmt er überall; „Ändern“ löst die Verknüpfung. In der Blutprobe ist „Blutprobe bei“ vorbelegt, wenn es genau eine beschuldigte oder betroffene Person gibt.
  - **Häusliche Gewalt im Vorgang:** Ihre Eintreffsituation steht nie doppelt. Gibt es den Abschnitt „Eintreffsituation“, wird sie dort als Absatz angehängt (eine Überschrift, eine Nummer) und die Ankunft muss in der Häuslichen Gewalt nicht noch einmal angetippt werden; gibt es ihn nicht, steht sie als eigener Punkt **vor** den Schilderungen. Tatort (aus der Einsatzörtlichkeit), Anrede und gemeinsamer Familienname (aus der Eintreffsituation) sind vorbelegt, solange du sie nicht selbst änderst.
  - **Was aufeinander aufbaut, zieht nach:** Namen, Rollen und die Art der Sache aus der Eintreffsituation; Besatzung und Amtsbezeichnungen aus „Allgemeines“ – auch bei den belehrenden, anwesenden und testenden Kräften in den Schilderungen. Nummern von Unfallbeteiligten werden über beide Abschnitte hinweg nur einmal vergeben.
  - **„Fertig“ heißt ohne Lücken:** Ein abgeschlossener Abschnitt mit fehlenden Pflichtangaben steht in der Übersicht als „n offen“; „Nachtragen“ führt zur Folie mit der Lücke. Ein Abschnitt ohne Inhalt lässt sich nicht abschließen.
  - **Gesamtsachverhalt:** alle Abschnitte hintereinander, je Abschnitt „Bearbeiten“ und „Kopieren“, dazu „Alles kopieren“; fehlende Angaben werden gezählt. Der Vorgang gilt als fertig, wenn alle Abschnitte fertig sind.
- **Zusatzbausteine** (Kachel „ZB“ und Knopf „Zusatzbausteine“ im Vorgang) – ein Untermenü für Seltenes, das nicht in jeden Bericht gehört. Antippen („+“) nimmt es auf, jedes reiht sich an seiner Stelle ein: Was **gleich aufgenommen** wird, öffnet sich sofort und steht im Vorgang ganz vorn; was **am Ende abgefragt** wird, wird nur angehakt und im letzten Abschnitt „Maßnahmen“ gefragt. Die Kachel legt einen Vorgang an und öffnet dort das Untermenü – so gehört, was vor Ort zuerst aufgenommen wird, von Anfang an zu dem Vorgang, in den später die übrigen Abschnitte kommen („Üblicher Anfang“ steht dort weiter bereit, solange noch kein gewöhnlicher Abschnitt angelegt ist). Welche Punkte es gibt, sagen die Module selbst (`m.zusatz`), neue kommen ohne Umbau dazu.
  - **Personenbeschreibung** (wird gleich aufgenommen, Abschnitt ganz vorn): geführte Abfrage der Person, die vor einem steht. Je Beschreibung eine **Übersicht der Überpunkte** untereinander – offene Punkte zeigen ihre Nummer und was dort gefragt wird, beantwortete den Haken und die Antwort. Man fragt **der Reihe nach** ab („Zurück / Weiter“, eine Folie je Überpunkt) **oder tippt nur an, wozu es Angaben gibt** – niemand drückt sich durch Folien, zu denen die Person nichts sagen kann. Die Reihenfolge folgt dem, was man an einem Menschen zuerst wahrnimmt und was Zeuginnen und Zeugen am häufigsten angeben können (Geschlecht, Alter, Größe, Statur, Erscheinungsbild, Haare – innere Gesichtszüge dagegen selten): *Wer beschreibt wen?* (Name als Freitext, nur für die eigene Zuordnung, Personen des Vorgangs als Vorschlag; Bezeichnung im Text: Täter/in, Tatverdächtige/r, unbekannte Person, in Verkehrssachen Fahrer/in) · **Körperliche Merkmale:** *Geschlecht und Alter*, *Größe und Statur*, *Erscheinungsbild*, *Haare* (Länge, Farbe, Frisur), *Bart* (Art, Farbe; entfällt bei „weiblich“) · **Bekleidung und besondere Merkmale:** *Bekleidung* (Schnellwahl **„Dunkel gekleidet“** – auch direkt in der Übersicht, ein Tipp und der Punkt ist erledigt –, Einzelheiten von oben nach unten), *Besondere Merkmale* (Narben, Tätowierungen, Brille, Schmuck, Mitgeführtes) · *Abschluss* („Sonst keine weiteren Angaben“, Wahllichtbildvorlage: danach gefragt und Antwort Ja / Nicht sicher / Nein). Was zusammengehört, steht auf einer Folie; zu Statur, Erscheinungsbild, Haaren und Bart gibt es je ein **freies Feld für Stichworte mit Komma**, um ins Einzelne zu gehen. Sobald etwas erfasst ist, liegt in der Übersicht unten neben „Fertig“ das **Kopieren** – zum schnellen Weitergeben auch mitten in der Abfrage.
    - **Alter und Größe** als *Von – bis* oder *Circa*. Von – bis: Leiste (Größe 160–210 cm, Alter 10–80 Jahre) mit zwei senkrechten Markierungen; ziehen setzt im 5er-Raster, **festhalten vergrößert den Bereich** unter dem Finger (erst 20, dann 10 Einheiten breit) – dann auf den Zentimeter bzw. das Jahr genau, loslassen übernimmt. Eine Markierung am Rand heißt „keine Angabe“: nur die linke bewegt → „mindestens 175 cm“, nur die rechte → „höchstens 185 cm“, beide auf demselben Wert → „ca. 180 cm“. Circa: ein Rad zum Drehen in 5er-Schritten, der Wert in der Mitte gilt. Auch per Tastatur bedienbar (Pfeile, Bild auf/ab, Pos1/Ende).
    - **Statur** als Skala in acht Stufen von schmal nach kräftig (hager, schmächtig, schlank, normal, sportlich, kräftig, stämmig, korpulent); zwei antippen ergibt eine Spanne („schlank bis sportlich“). **Erscheinungsbild** mit neutralen, geografischen Bezeichnungen (mittel-, nord-, ost-, südost-, südeuropäisch, nordafrikanisch, west-, süd-, ostasiatisch, afrikanisch, mittel-/südamerikanisch) und dem im Bericht üblichen „südländisch“, höchstens zwei („… oder …“). **Haarfarbe** hell, blond, dunkelblond, rot, braun, dunkelbraun, schwarz, dunkel, grau, weiß; **Haarlänge** Glatze, sehr kurz, kurz, mittellang, schulterlang, lang; **Bart** kein Bart, Dreitagebart, Oberlippenbart, Kinnbart, Oberlippen- und Kinnbart, Vollbart, langer Vollbart – Farbe wie bei den Haaren, „Wie die Haare“ übernimmt sie.
    - **Text:** gegliedert in zwei Blöcke – **Körperliche Merkmale** (was zum Menschen selbst gehört) und **Bekleidung und besondere Merkmale** –, wahlweise als **Liste** (Vorgabe: je Merkmal eine Zeile, reiner Text, übersichtlich und in jedes andere Programm kopierbar) oder als **Fließtext**; der Umschalter gilt für alle Beschreibungen des Abschnitts. Liste: „Frau Müller beschrieb den Täter wie folgt: / Körperliche Merkmale: / – Geschlecht: männlich / – Alter: 30 bis 35 Jahre / – Haare: kurz, dunkelblond / Bekleidung und besondere Merkmale: / – Bekleidung: dunkel gekleidet / Weitere Angaben zu dem Täter konnten nicht gemacht werden.“ Fließtext: „… wie folgt: männlich, 30 bis 35 Jahre alt, kurze dunkelblonde Haare. Bekleidung: dunkel gekleidet. Besondere Merkmale: Narbe an der linken Wange. Weitere Angaben …“ **Was nicht beantwortet wird, steht nicht im Text und wird nicht verneint** – dafür gibt es den einen Schlusssatz; er ist vorgewählt, sobald etwas beschrieben ist und anderes offen blieb (abwählbar, eine Abwahl bleibt stehen). Ohne Namen steht der Einleitungssatz im Passiv. „Fertig“ zeigt den Text sofort zum Kopieren; im Gesamtsachverhalt steht er als erster Abschnitt (ohne Nummer – er zählt bei der Gliederung nicht mit). **Nachtragen:** Unter dem fertigen Text stehen die Überpunkte als Sprungmarken, gegliedert wie die Ausgabe (✓ = dort steht schon etwas) – Antippen öffnet die passende Stelle, „Fertig“ führt zurück zum Text. Dasselbe gibt es bei der Fahrzeugbeschreibung.
    - **Mehrere Personen:** Geht es um mehr als eine Person, werden die Beschreibungen **von selbst durchnummeriert** („die unbekannte Person 1“, „… 2“) – eine weitere Beschreibung übernimmt Bezeichnung und Darstellung der ersten, der Name des Zeugen steht als Vorschlag bereit. Die Nummer lässt sich von Hand ändern: Beschreiben zwei Zeugen dieselbe Person, bekommt sie bei beiden dieselbe Nummer und zählt als eine (ein zweiter Tipp auf die gewählte Nummer gibt sie wieder frei). **Die Nummern bleiben lückenlos:** Fällt eine Beschreibung weg, rücken die von selbst vergebenen auf (1, 3 → 1, 2); von Hand gewählte bleiben. Im Text steht die Nummer nur, wenn es um mehr als eine Person geht – beschreiben zwei Zeugen denselben einen Täter, heißt er bei beiden „der Täter“. Die **Bezeichnung** („Täter/in“, in Verkehrssachen „Fahrer/in“) gilt so, wie sie beim Eintragen zu sehen war – kommt die Art der Sache erst später in den Vorgang, kippt der Text nicht nachträglich. Auf der Folie „Wer beschreibt wen?“ (und in der Liste der Beschreibungen) steht **„Wie viele Personen waren es insgesamt?“** – auch wenn nicht alle beschrieben werden; Zahlen unter der Zahl der schon beschriebenen Personen sind gesperrt. Daraus entsteht der **Einleitungssatz**: „Nach Zeugenangaben handelte es sich um drei Täter, von denen zwei beschrieben werden konnten.“ (ohne Gesamtzahl: „Es wurden zwei Täter beschrieben.“). Steht die Beschreibung in einer Schilderung, spricht der Satz von der Person: „Die Zeugin Müller gab an, dass es sich um drei Täter gehandelt habe, von denen sie zwei beschreiben könne.“ Mehrere Fahrzeuge werden ebenso durchnummeriert.
    - **Bei der Schilderung übernehmen:** Die Beschreibung gehört zunächst zu niemandem. In den Schilderungen hat jede Person die Folie „Hat … jemanden beschrieben?“ – antippen übernimmt sie (was zum Namen passt, steht oben). Sie steht dann hinter der Schilderung mit Rolle und Namen („Die Zeugin Müller beschrieb den Täter wie folgt: … Weitere Angaben zu dem Täter könne sie nicht machen.“) und vorn im Gesamtsachverhalt nicht noch einmal. Änderungen an der Beschreibung kommen dort an; solange es Schilderungen gibt und eine Beschreibung nirgends übernommen ist, zeigt der Abschnitt „1 offen“. Macht die Person doch **keine Angaben**, wird die Beschreibung wieder frei und steht vorn – sie verschwindet nicht stillschweigend aus dem Bericht.
  - **Fahrzeugbeschreibung** (wird gleich aufgenommen, Abschnitt vorn nach der Personenbeschreibung): dieselbe Bedienung wie die Personenbeschreibung – Übersicht der Überpunkte, **der Reihe nach abfragen** oder **nur antippen, wozu es Angaben gibt**, unten „Kopieren“ und „Fertig“. Reihenfolge vom Groben zum Feinen: *Wer beschreibt was?* (Name für die eigene Zuordnung; Bezeichnung im Text: Fahrzeug, Fluchtfahrzeug, Tatfahrzeug) · **Fahrzeug:** *Art und Form* (Pkw, Transporter, Lkw, Motorrad, Roller, Fahrrad, E-Scooter; die Formen richten sich nach der Art – Kleinwagen, Limousine, Kombi, SUV, Van, Coupé, Cabrio, Pick-up …), *Farbe* (elf Farben, dazu **hell/dunkel** – für sich „dunkel“ oder vor der Farbe „dunkelblau“; als Schnellwahl direkt in der Übersicht), *Marke und Modell* (gängige Marken zum Antippen, Modell frei, **„vermutlich“**, weil Zeugen sich hier eher irren als bei der Farbe), *Kennzeichen* (so, wie es genannt wird; „Nur ein Bruchstück“ → „Kennzeichenfragment“), *Besonderheiten* (frei) · **Insassen und Fahrtrichtung:** *Insassen* (wer wo einstieg, Besetzung, Freitext), *Fahrtrichtung* („Bahnhof“ → „… entfernte sich in Richtung Bahnhof“) · *Abschluss* („Sonst keine weiteren Angaben“, vorgewählt, sobald etwas beschrieben ist und anderes offen blieb).
    - **Verknüpfung mit der Personenbeschreibung:** Sind im selben Vorgang Personen beschrieben, stehen sie beim Punkt „Insassen“ zur Wahl – in der Übersicht als Schnellwahl „Der Täter als Fahrer“. Die Plätze richten sich nach der Fahrzeugart (Pkw: Fahrer, Beifahrer, hinten links, hinten rechts, hinten · Transporter: Fahrer, Beifahrer, Schiebetür, Laderaum · Motorrad/Roller: Fahrer, Sozius · Fahrrad/E-Scooter: fuhr damit). Im Text: „– Eingestiegen: der Täter als Fahrer auf der Fahrerseite“ bzw. „Der Täter stieg als Fahrer auf der Fahrerseite ein.“ Ändert sich bei der Person Geschlecht, Bezeichnung oder Nummer, stimmt der Satz auch hier (bei einer Frau „als Fahrerin“ bzw. „als Sozia“; heißt die Person ohnehin „Fahrzeugführer“, steht „als Fahrer“ nicht noch einmal dabei). **Was zusammengehört, bleibt stimmig:** Nur eine Person fährt – wird eine zweite als Fahrer gewählt, löst sie die erste ab. Die Besetzung ist nie kleiner als die Zahl der Eingestiegenen. Wechselt die Fahrzeugart, wandern die Plätze mit (Beifahrer ↔ Sozius) oder entfallen mit Hinweis. Haben zwei Zeugen dieselbe Person beschrieben, steht sie nur einmal zur Wahl. Wird eine Personenbeschreibung gelöscht, entfällt auch, wo diese Person eingestiegen ist (die Rückfrage beim Löschen sagt es) – sonst bliebe ein Name stehen, den es im Bericht nicht mehr gibt. **Beides ist unabhängig voneinander nutzbar**, in beliebiger Reihenfolge: Ein Fahrzeug ohne Bezug zu einer Person bleibt einfach ohne – jemand, der nicht eigens beschrieben ist, lässt sich eintragen und heißt im Text „eine Person“ – oder „eine weitere Person“, wenn vor ihr schon jemand genannt ist.
    - **Gemeinsam kopieren:** Gibt es im Vorgang beides, bietet der Abschluss beider Abschnitte „Mit Fahrzeugbeschreibung kopieren“ bzw. „Mit Personenbeschreibung kopieren“ – erst die Person, dann das Fahrzeug, in einem Stück zum Weitergeben. Text wie bei der Personenbeschreibung als **Liste** (Blöcke „Fahrzeug“ und „Insassen und Fahrtrichtung“) oder **Fließtext**; in den Schilderungen bei der Person übernehmbar, die das Fahrzeug beschrieben hat („Die Zeugin Müller beschrieb das Fluchtfahrzeug wie folgt: …“).
  - **Maßnahmen** (wird am Ende abgefragt, letzter Abschnitt): fragt nur, was im Untermenü gewählt wurde; unter „Fällt dir noch etwas ein?“ lässt sich jeder weitere Punkt dort nachträglich dazunehmen, das kleine ✕ nimmt einen wieder heraus. Jede Antwort wird ein Satz, in dieser Reihenfolge:
    - **Nahbereichsfahndung:** durchgeführt Ja / Nein, bei Ja optional das Ergebnis (ohne oder mit Erfolg) – keine Vorwahl.
    - **Qualifizierte Spurensicherung:** *Erfolgt* („… erfolgte durch das zuständige Kommissariat bzw. die zuständige Fachdienststelle. Hierzu wird ein gesonderter Bericht gefertigt.“ – eine der beiden Stellen lässt sich antippen) oder *Verzichtet* („Mangels verwertbarer Spurenlage oder zu erwartender Spuren wurde auf eine qualifizierte Spurensicherung verzichtet.“) – bewusst ohne Vorwahl, hier kommt es auf die Antwort an.
    - **Videoaufzeichnungen:** *Absuche vor Ort* nach Geräten, die das Geschehen aufgezeichnet haben könnten – bei „Nein“ steht dazu nichts im Text; bei „Ja“: Gerät festgestellt?, wo (Satzbaustein), was daraufhin geschah (freie Sätze). *Angaben einer Person*, dass Aufzeichnungen bestehen: Person aus dem Vorgang antippen (heißt wie in Eintreffsituation und Schilderungen und folgt Berichtigungen dort; steht sie nicht mehr im Vorgang, bleibt ihr Wortlaut stehen und lässt sich über den Chip „nicht mehr im Vorgang“ herausnehmen) oder frei eintragen; sichert die Aufzeichnungen, hält sie auf Nachfrage bereit oder reicht sie selbstständig ein; vor Ort aufgerufen und von den eingesetzten Beamten gesichtet → tatrelevante Feststellungen Ja / Nein → bei Ja: Lichtbilder gefertigt? → der Lichtbildmappe beigefügt? („Ja“ nimmt die Lichtbildmappe mit „erstellt“ in den Bericht.)
    - **Lichtbildmappe:** erstellt Ja / Nein – „Ja“ ist vorgewählt, wer sie im Untermenü antippt, hat sie in aller Regel vor.
- **Eintreffsituation** (Kachel „ES“) – Öffner für die Folgeabschnitte, unabhängig vom Einsatzanlass (Körperverletzung, Diebstahl, Verkehrsunfall …):
  - **Worum geht es?** Strafanzeige oder Verkehrsangelegenheit – dieselben Namensregeln wie bei den Schilderungen.
  - **Personen vor Ort** mit einem Tipp auf die Rolle: Zeuge/Zeugin, Geschädigte/r, Beschuldigte/r, Betroffene/r (OWi), Betroffene/r (Maßnahme), in Verkehrsangelegenheiten zusätzlich **Unfallbeteiligte/r 01, 02 …** (01 ist die Verursacherin oder der Verursacher; wer als 01 gewählt wird, tauscht mit der bisherigen 01). In der Maske der Person steht alles zu ihr: Anrede, Nachname, Vorname, **wo sie angetroffen wurde** und die **Verletzungen** – dieselbe Auswahl wie in den Schilderungen (Nicht verletzt, Nur Schmerzen, Verletzt, Lichtbilder, Rettungswagen, Attest).
  - **Wo angetroffen?** direkt bei der Person: **wie** – angetroffen, erwartete uns, hielt sich dort auf, nicht mehr vor Ort – und **wo**, als Satzbaustein in einem Textfeld mit dem fertigen Satz darüber („Bei unserem Eintreffen wurde der Zeuge Müller … angetroffen.“), dazu eine Ergänzung als ganzer Satz. Ab der zweiten Person steht dort die Wahl **Allein** oder **Zusammen mit …** (je vorhandenem Ort ein Knopf mit den Namen und dem Ort): Zusammen übernimmt den Ort der anderen, im Text steht „gemeinsam“, und was man einträgt, gilt für alle an diesem Ort; zurück auf „Allein“ bringt die eigenen Angaben wieder. Bei „Nicht mehr vor Ort“ entfallen Ort und Verletzungen. Die Übersicht zeigt je Person Rolle, Ort und Verletzung, darunter optional die Uhrzeit des Eintreffens und „Weitere Feststellungen“.
  - **Schnellwahl „Wohngebäude“:** ein Entscheidungsbaum, der immer nur die nächste Frage zeigt und den Ort Schritt für Schritt genauer macht: *Gebäude* (Einfamilienhaus · Doppelhaushälfte → linke/rechte Hälfte · Reihenhaus → End-/Mittelhaus · Mehrfamilienhaus · Hochhaus · Wohn- und Geschäftshaus · Gemeinschaftsunterkunft) → *Wo am oder im Gebäude?* → **vor dem Gebäude** (vor dem Haus, vor der Haustür, Gehweg, Straße, Einfahrt, Parkplatz, Garten; beim Einzelhaus Vorgarten, Terrasse, Garage; bei Mehrparteien Hof) · **an der Tür** (Haustür; bei Mehrparteien Wohnungstür → Geschoss → Seite) · **im Gebäude** (nur Mehrparteien: Hauseingang, Treppenhaus oder Hausflur → Geschoss, Aufzug, Keller, Tiefgarage, Dachboden, Waschküche) · **in der Wohnung / im Haus** (Geschoss → Seite links/Mitte/rechts → Raum). Jede Antwort schreibt den Satzbaustein ins Textfeld („im Wohnzimmer der Wohnung im 2. Obergeschoss links des Mehrfamilienhauses“), wo er sich von Hand ändern lässt; die bisherigen Antworten stehen als Wegleiste da – antippen wählt ab dort neu, „Überspringen“ lässt eine Frage offen. Bei der nächsten Person ist das Gebäude der vorigen vorbelegt.
  - **Text:** je Ort ein Absatz – „Bei unserem Eintreffen um 19:25 Uhr wurden der Geschädigte Meier und die Zeugin Schulz gemeinsam vor dem Mehrfamilienhaus angetroffen.“ –, danach die Verletzungen der dort angetroffenen Personen (bei einer einzelnen Person mit „Er/Sie …“). Personen ohne Ort stehen als [Platzhalter] da. **Abschließen** zeigt den Abschnitt mit Nummer (Standard 2, frei oder ohne) zum Kopieren.
- **Schilderungen** – die Schilderungen aller Personen eines Vorgangs nacheinander erfassen und als Paket in die Anzeige kopieren:
  - **Worum geht es?** *Strafanzeige* (Nachname ausgeschrieben, bei gleichem Nachnamen mit Vorname) oder *Verkehrsangelegenheit* (nur Anfangsbuchstabe „M.“; teilen sich Personen den Buchstaben, kommt der des Vornamens davor „A. M.“, reicht das nicht, der zweite „An. M.“).
  - **Person hinzufügen** mit einem Tipp auf die Rolle – fünf Rollen: Zeuge/Zeugin, Geschädigte/r (Belehrung wie bei Zeugen), Beschuldigte/r, **Betroffene/r (OWi)** – im Ordnungswidrigkeitenverfahren, belehrt nach § 55 OWiG mit eröffnetem Vorwurf – und **Betroffene/r (Maßnahme)** – Betroffene einer polizeilichen Maßnahme, **ohne Belehrung**: Die Folie heißt dann nur „Verständigung“, im Text steht „Der Betroffene Kurz machte gegenüber POK Schulz sinngemäß folgende Angaben:“ (im Text heißen beide „der Betroffene“). In Verkehrsangelegenheiten zusätzlich **Unfallbeteiligte/r 01, 02 …** – im Text „der Unfallbeteiligte 01 (M.)“, Überschrift „Schilderung des Unfallbeteiligten 01 (M.)“. 01 ist die Verursacherin oder der Verursacher: Pflichtauswahl **Belehrt als** Beschuldigte/r oder Betroffene/r (danach Tatvorwurf, Belehrungssatz und „keine Angaben zur Sache“ wie bei dieser Rolle); 02 und weitere werden als Zeugen belehrt. Die Nummer lässt sich ändern, doppelte tauschen. Je Person: Anrede, Name, **belehrt durch** (Namen tippen – Vorschläge aus Besatzung und Team, im Text Amtsbezeichnung + Nachname; fehlt die Amtsbezeichnung, steht eine Auswahl daneben), **gegenüber** (Chip mit der belehrenden Person, „den eingesetzten Beamten“ oder weitere Namen), bei Zeugen und Geschädigten der Chip **Besonderer Hinweis auf das Zeugnisverweigerungsrecht** (im Text „gemäß § 52 StPO“, dazu „erklärte sich … zur Aussage bereit“, abwählbar) und die **Schilderung**.
  - Satzbau nach Geschlecht und Rolle: „Nach erfolgter zeugenschaftlicher Belehrung durch POKin Schulz machte die Zeugin Müller dieser gegenüber sinngemäß folgende Angaben:“ – ist nur die belehrende Person Gesprächspartner, steht „diesem/dieser gegenüber“; „den eingesetzten Beamtinnen“, wenn nur Beamtinnen eingesetzt sind.
  - **Reihenfolge in Maske und Text** wie im Einsatz: Person → Verletzungen → Verständigung und Belehrung → Alkohol und Drogen → Schilderung → Strafantrag. Gibt es Hinweise auf Alkohol oder Drogen, steht die Belehrung als eigener Satz vorn („Herr Schneider wurde durch PHK Becker als Beschuldigter belehrt.“), danach Wahrnehmungen, Fragen zum Konsum, Folgefähigkeit und Tests – jeweils mit dem Hinweis auf die Freiwilligkeit –, zuletzt „Zum Sachverhalt machte er gegenüber … sinngemäß folgende Angaben:“ und die Schilderung.
  - **Deutschkenntnisse** je Person: *problemlos* (kein Text), *eingeschränkt* oder *kein Deutsch* – dann Verständigung (Übersetzungs-App, Dolmetscher/in, Person vor Ort, andere Sprache) und ob nach dem Eindruck der Beamten alles verstanden wurde.
  - **Hinweise auf Alkohol und/oder Drogen** je Person: 76 Wahrnehmungen in zehn Gruppen (Geruch, Augen, Gesicht und Haut, Sprache, Gang und Motorik, Verhalten, Bewusstsein, Körper, Tests vor Ort, Umfeld) – es erscheinen nur die, die zu Alkohol, Drogen oder beidem passen. Dazu eigene Wahrnehmungen, Angaben zum Konsum, **Folgefähigkeit** („nach den Wahrnehmungen“ oder „wirkte so“), **Atemalkoholtest** (durch wen, Uhrzeit, Vortest oder beweissicher, Wert in mg/l) und **Drogenvortest** (Urin oder Speichelwischtest, durch wen, Uhrzeit, Ergebnis mit Stoffgruppen); auch „abgelehnt“ und „nicht möglich“. Im Text: „Bei dem Beschuldigten … ergaben sich vor Ort Hinweise auf … Folgende Wahrnehmungen und Feststellungen konnten bei ihm getroffen werden:“ mit Aufzählung.
  - **Keine Angaben:** Chip im Abschnitt Schilderung – Beschuldigte und Betroffene „… erklärte, keine Angaben zur Sache machen zu wollen.“, Zeugen mit § 52 „… von ihrem Zeugnisverweigerungsrecht Gebrauch zu machen.“, sonst „… keine Angaben zum Sachverhalt machen zu wollen.“ Gegenüber und Schilderungsfeld entfallen dann.
  - **Belehrung:** bei Beschuldigten und Betroffenen der eröffnete (Tat-)Vorwurf mit Vorschlägen, Chip „Hat erklärt, die Belehrung verstanden zu haben“. Mit dem Chip stehen zwei Sätze da („… erklärte …, diese verstanden zu haben. Zum Sachverhalt machte er gegenüber … sinngemäß folgende Angaben:“) – kein „…, und machte …“. Die Uhrzeit der Belehrung wird nicht erfasst.
  - **Gegenüber wem:** die belehrende Person, einzelne Namen oder **Alle** – dann steht „gegenüber den eingesetzten Beamten“ im Text, ohne Aufzählung der Namen.
  - **Beobachtung statt Wertung:** Die Auffälligkeiten stehen mit den feststellenden Beamten im Text („PHK Becker und PK Wagner stellten bei ihm vor Ort folgende Auffälligkeiten fest, die auf … hinwiesen:“); wertende Punkte (z. B. „aggressiv“, „distanzlos“) verlangen ein Beispiel in Klammern. Folgefähigkeit mit Belegen („beantwortete Fragen sinnvoll …“) und Hinweis, wenn sie eingeschränkt ist, die Belehrung aber nicht als verstanden vermerkt.
  - **Tests vor Ort** (Finger-Nase, Romberg mit Zeitschätzung, Einbeinstand, Linie, Drehbewegung) als eigener Teil mit Hinweis auf die Freiwilligkeit. **Atemalkoholtest** mit Gerät (zuletzt benutzte Geräte zum Antippen), Trinkende laut eigener Angabe und Beobachtung seit (Nachtrunk). **Drogenvortest:** Speichel – Drugwipe, Urin – nal von minden; im Text als Vortest bezeichnet.
  - **„gegenüber den eingesetzten Beamten“** wird mit den Namen der Besatzung ausgeschrieben.
  - **Verletzungen** (alle Rollen, ganz vorn vor der Belehrung): *Nicht verletzt*, *Nur Schmerzen* („… gab an, Schmerzen … zu haben.“) oder *Verletzt* („… wurden folgende Verletzungen festgestellt: …“) – Ort und Art als freier Text. Bei festgestellten Verletzungen Lichtbilder ja/nein. Rettungswagen: *braucht keinen (auf Nachfrage)* – dann Hinweis auf die Möglichkeit eines Attests und die Reaktion darauf (reicht nach / will keins / offen) – oder *hinzugezogen* mit Transport ins Krankenhaus (Name frei, zuletzt benutzte zum Antippen) bzw. ambulanter Behandlung und Entlassung vor Ort.
  - **„Nicht verletzt“ nur auf Wunsch im Text:** Der Satz „… gab an, nicht verletzt zu sein; Verletzungen waren nicht erkennbar.“ steht nur da, wenn das Häkchen „Im Text erwähnen“ gesetzt ist. Die Angabe zu Verletzungen ist keine Pflicht – die Folie kann leer bleiben, auch in der Eintreffsituation.
  - **Strafantrag** (nur Geschädigte, eigener Abschnitt am Ende): *Ja, mündlich gestellt* – im Text mit ausdrücklichem Verfolgungswillen, auf Wunsch „vor Ort unterschrieben“ oder „Vordruck ausgehändigt“ (§ 158 Abs. 2 StPO verlangt seit Juli 2024 keine Schriftform mehr, aber feststehende Identität und Verfolgungswille); *Behält sich vor* oder *Nein* – jeweils mit vorgewähltem, abwählbarem Hinweis auf die Frist von drei Monaten (§ 77b StGB).
  - **Mehrere Personen:** Der Chip **Getrennt voneinander befragt** (Personenliste, ab zwei Abschnitten) setzt den Satz unter die Überschrift: „Die nachfolgend genannten Personen wurden getrennt voneinander befragt.“ Wer **gleichzeitig mit einer anderen Person belehrt** wurde und übereinstimmend dasselbe angab, wählt auf der Folie „Belehrung“ **Gemeinsam mit …** – beide stehen dann in einem Abschnitt („Schilderung des Herrn Müller und der Frau Meier“, „Nach gleichzeitiger zeugenschaftlicher Belehrung durch POK Schulz machten der Zeuge Müller und die Zeugin Meier diesem gegenüber gemeinschaftlich und übereinstimmend sinngemäß folgende Angaben:“). Belehrung, Gegenüber und Schilderung stehen bei der Person, die den Abschnitt führt; Verletzungen, Deutschkenntnisse, Personenbeschreibung und Strafantrag bleiben je Person. Möglich für Zeugen und Geschädigte ohne Hinweise auf Alkohol oder Drogen; gibt es beides nebeneinander, heißt der Satz „Soweit nachfolgend nicht anders vermerkt, wurden die Personen getrennt voneinander befragt.“
  - **Personen- und Fahrzeugbeschreibung übernehmen** (im Vorgang, wenn über die Zusatzbausteine eine aufgenommen wurde): eigene Folie nach der Schilderung („Hat … jemanden oder ein Fahrzeug beschrieben?“) – siehe Zusatzbausteine.
  - **Abschließen** zeigt den fertigen Abschnitt mit Kopieren und führt zurück zur Liste (Reihenfolge mit ↑ änderbar). **Alle Schilderungen hinzugefügt** → Abschnittsnummer wählen (2–6 oder frei, z. B. 3) → **Gesamtpaket** „3 Schilderungen“ mit „3.1 Schilderung der Frau …“, „3.2 …“ – ohne Punkt hinter der Zahl, „3.1“ direkt unter „3“ ohne Leerzeile. Übernommene Personen- und Fahrzeugbeschreibungen stehen durch einen Absatz abgesetzt unter der Schilderung (und dem Strafantrag); in der Listenform folgt nach dem letzten Spiegelstrich ein Absatz, dann der Schlusssatz („Weitere Angaben zu dem Täter könne sie nicht machen.“). `⌘/Strg + Enter` schließt eine Person ab bzw. kopiert das Paket.

**Tastatur:** `N` neu (je nach Bereich) · `/` suchen · `1`–`7` Bereiche · `S` schreiben · `D` dongeln · `E` Einsatz · `L` sperren · `Strg/⌘ + Enter` speichern bzw. weiter

**Backups:** *⋯ → Verschlüsseltes Backup* speichert eine `.vault`-Datei. Einspielen geht per Zusammenführen oder Ersetzen.
